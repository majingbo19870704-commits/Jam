# M0 上手指南

M0 阶段交付了完整的应用基座，可直接跑起来体验：账号创建/登录 → 进入主界面 → 8 大模块间自由切换 → 系统设置里切换主题色。

## 前置条件

参见 [setup.md](./setup.md)。至少需要装好：

- Node.js 20+
- Rust stable
- Microsoft C++ Build Tools（Windows）
- WebView2 Runtime（Windows 11 默认已装）

## 首次运行

在英文路径下打开 PowerShell（例如 `C:\dev\`），然后：

```powershell
# 假设你已经把 personal-workstation 目录复制过来
cd personal-workstation

# 安装前端依赖
npm install

# 前端热更新（可选，只看 UI 时用）
npm run dev

# 完整 Tauri 应用（推荐）—— 首次会拉 Rust 依赖，耐心等 3-8 分钟
npm run tauri:dev
```

## 应该看到什么

首次启动时应用没有任何账号，会自动跳到"新建账号"页：

1. **新建账号**：填账号名 / 显示名 / 密码 → 提交
2. **保存恢复码**：一次性显示的 4 组 16 位大写字母数字（例如 `X8QK-9F2Z-A1B7-M3P4`），点复制或手抄
3. 点"进入工作站"，落到**主页看板**

之后关闭再打开应用，会看到**账号选择页**：点头像 → 输入密码 → 登录。

## 界面

- 左侧浅蓝色**侧栏**，8 个一级模块图标 + 名称，工作管理 / 项目管理右侧带红色计数徽章（当前为占位数字）
- 顶部**日期条**（`2026-09-24 · 周四 · 农历八月十三`）+ 全局搜索 + 通知 + 头像
- **主页看板**：5 个多彩快捷入口方块 + 12 栅格占位卡（M2 阶段填入真实数据）
- **工作管理 / 项目管理 / 知识管理 / 英语 / AI / 快捷链接**：Construction 占位页，标注预计交付阶段
- **系统设置**：主题色切换（深邃蓝 / 生机绿 / 樱花粉 / 优雅紫），点击即时生效并持久化

## 数据存储位置

- 开发模式：`%APPDATA%\com.majin.personal-workstation\data.db`
- 打开这个 db 文件可以用 DB Browser for SQLite 验证 schema 是否正确应用（应有 19 张业务表 + 4 张 FTS 虚拟表）

## 已知边界

- 多账号的账号切换 UI 已经完整，但 M0 不做同账号内的"重命名 / 删除账号"，M1 补齐
- 密码错误校验依赖后端 Rust 的 Argon2；如果启动时 Rust 依赖没装全，会在提交表单时报"invoke error"
- 主页看板的仪表卡在 M0 是占位，M2 阶段接入真实 SQL 查询
